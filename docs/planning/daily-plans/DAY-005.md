## 4. Technical Specifications
- **Cloud Database:** Supabase PostgreSQL 16 (Region Singapore: `ap-southeast-1`)
- **Cloud Storage:** Supabase Storage
  - Bucket `public-rooms`: Public read access, tối đa 5 file/phòng
  - Bucket `private-documents`: Private read access, truy cập qua Signed URL (TTL 1 giờ)
- **Payment Gateway:** SePay Test Mode / Production
  - Protocol: VietQR (NAPAS247 image URL) + Inbound Webhook HTTP POST
  - QR URL Template: `https://qr.sepay.vn/img?acc={acc}&bank={bank}&amount={amount}&des={des}`
  - Authentication: `SEPAY_API_KEY`, Webhook verification via `SEPAY_WEBHOOK_SECRET`
- **Transactional Email:** Resend API (HTTPS API Key) & Mailtrap SMTP (Port 2525)

## 5. Business Rules & Ràng Buộc

- **NFR-01:** Thời gian phản hồi < 3 giây (được hỗ trợ bởi Supabase Singapore datacenter).
- **NFR-06:** Ảnh CCCD và file hợp đồng PDF bắt buộc lưu trữ tại private bucket, truy cập bằng URL có chữ ký điện tử.
