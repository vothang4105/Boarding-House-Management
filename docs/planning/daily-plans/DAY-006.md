## 4. Technical Specifications

### Mô hình Dữ liệu Phân quyền theo Dãy (BR-14)
- **Thực thể liên kết:**
  ```csharp
  public class BuildingManager
  {
      public Guid Id { get; set; }
      public Guid UserId { get; set; }
      public Guid BuildingId { get; set; }
      public DateTime AssignedAt { get; set; }

      public virtual User User { get; set; }
      public virtual Building Building { get; set; }
  }
  ```
- **Nguyên tắc lọc truy vấn EF Core Global Query Filter:**
  - `User.Role == Owner`: Bỏ qua bộ lọc (Toàn quyền truy cập tất cả các dãy).
  - `User.Role == Manager`: Tự động lọc `BuildingId` thuộc danh sách `AssignedBuildingIds` của Manager hiện tại.
  - `User.Role == Tenant`: Tự động lọc dữ liệu gắn với `TenantId` hoặc `RoomId` của hợp đồng đang hiệu lực.

### Kiến trúc Xác thực & Phân quyền (NFR-05)
- **JWT Claims:** `sub` (UserId), `email`, `role` (OWNER | MANAGER | TENANT), `building_ids` (mảng Guid nếu role là MANAGER).
- **Custom Authorization Requirement:** `BuildingScopeRequirement` và `BuildingScopeHandler` xác thực tham số `buildingId` trên Route/Query khớp với phạm vi được cấp phép.
