## 4. Technical Specifications
- **Cấu trúc Monorepo:**
  ```text
  Boarding-House-Management/
  ├── .agent/               # Agent rules & skills
  ├── backend/              # ASP.NET Core .NET 10 Web API
  ├── frontend/             # Next.js TypeScript App
  ├── docs/                 # SRS, Master Plan, Daily Plans, Dev Log
  ├── scripts/              # Automation & Scope verification scripts
  ├── docker-compose.yml    # PostgreSQL 16 local database
  ├── .gitmessage           # Conventional commits template
  ├── .gitignore            # Multi-stack ignore rules (.NET + Node + Env)
  ├── AGENTS.md
  └── README.md
  ```
- **Quy tắc Conventional Commits:**
  - `feat(<scope>): <description>`: Tính năng mới
  - `fix(<scope>): <description>`: Sửa lỗi
  - `docs(<scope>): <description>`: Cập nhật tài liệu
  - `chore(<scope>): <description>`: Cấu hình build, tooling, cấu trúc
  - `refactor(<scope>): <description>`: Tái cấu trúc không đổi logic
