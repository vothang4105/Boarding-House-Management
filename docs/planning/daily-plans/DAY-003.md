# Daily Implementation Plan - DAY-003

## 1. Objective (Mục tiêu cốt lõi)
Xây dựng tài liệu Ma trận Truy vết Yêu cầu (Requirement Traceability Matrix - RTM) hoàn chỉnh để liên kết đa chiều toàn bộ 48 Yêu cầu Chức năng (FR-01 đến FR-48), 14 Quy tắc Nghiệp vụ (BR-01 đến BR-14), và 13 Yêu cầu Phi chức năng (NFR-01 đến NFR-13) với các Module hệ thống, Thực thể Database và Kế hoạch phân bổ Sprint trong 16 tuần, đảm bảo 0% yêu cầu Must-have bị bỏ sót (Deliverable 7.1 từ BA).

---

## 2. Tasks (Thứ tự thực hiện chi tiết)

### Task 1: Thiết kế Cấu trúc Ma trận RTM (08:30 – 10:00)
- Thiết lập khung bảng RTM chuẩn gồm các trường:
  - `Mã Yêu cầu (FR / NFR ID)`
  - `Mô tả Yêu cầu`
  - `Mức ưu tiên MoSCoW (M / S)`
  - `Module Hệ thống`
  - `Actor chính`
  - `Thực thể Dữ liệu liên quan (Entities)`
  - `Quy tắc Nghiệp vụ ràng buộc (BRs)`
  - `Sprint / Giai đoạn triển khai`
  - `Tiêu chí kiểm thử / Phương pháp nghiệm thu`

### Task 2: Ánh xạ Chi tiết 48 Yêu cầu Chức năng (FR-01 đến FR-48) (10:00 – 14:00)
- Ánh xạ đầy đủ 8 module chức năng từ `docs/requirements/SRS.md`:
  1. Quản lý Nhà & Phòng (`FR-01` -> `FR-06`)
  2. Khách thuê & Hợp đồng (`FR-07` -> `FR-14`)
  3. Chỉ số Điện & Nước (`FR-15` -> `FR-20`)
  4. Hóa đơn & Thanh toán (`FR-21` -> `FR-29`)
  5. Sự cố / Bảo trì (`FR-30` -> `FR-35`)
  6. Thông báo & Nhắc nhở (`FR-36` -> `FR-38`)
  7. Báo cáo & Dashboard (`FR-39` -> `FR-43`)
  8. Quản trị Người dùng (`FR-44` -> `FR-48`)
- Đối chiếu ràng buộc các quy tắc nghiệp vụ `BR-01` đến `BR-14` vào từng FR tương ứng.

### Task 3: Ánh xạ 13 Yêu cầu Phi chức năng (NFR-01 đến NFR-13) (14:00 – 16:30)
- Ánh xạ các chỉ số kỹ thuật: Hiệu năng (< 3s Dashboard, < 30s Hóa đơn), Bảo mật (Bcrypt cost $\ge$ 10, JWT, Signed URL), Tính tương thích (Responsive $\ge$ 360px), Offline mode (Dexie.js), Audit log (SaveChangesInterceptor), Backup, Múi giờ UTC+7.
- Xác định tầng kiến trúc phụ trách (Frontend Next.js, Backend .NET 10, PostgreSQL Supabase).

### Task 4: Kiểm toán Scope, Tổng kết ngày (DoD) & Bàn giao (16:30 – 17:30)
- Kiểm tra tính đầy đủ và toàn vẹn của file `docs/requirements/RTM.md`.
- Chạy kiểm toán phạm vi file bằng script `scripts/verify-scope.ps1`.
- Cập nhật nhật ký phát triển `docs/development/DEVELOPMENT_LOG.md`.
- Đánh dấu trạng thái hoàn thành `COMPLETED` cho DAY-003.
