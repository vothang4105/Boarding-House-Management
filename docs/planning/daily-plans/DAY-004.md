# Daily Implementation Plan - DAY-004

## 1. Objective (Mục tiêu cốt lõi)
Sẵn sàng hạ tầng lập trình trên máy cá nhân (.NET 10 SDK, Node.js LTS, Docker PostgreSQL UTC+7), khởi tạo khung Solution .NET 10 trong `backend/` và ứng dụng Next.js trong `frontend/` để kiểm chứng toàn bộ trình biên dịch, package manager và container database sẵn sàng cho giai đoạn phân tích thiết kế Database và code.

---

## 2. Tasks (Thứ tự thực hiện chi tiết)

### Task 1: Kiểm tra Phiên bản Công cụ Môi trường (08:30 – 09:00)
- Kiểm tra phiên bản các công cụ cài đặt trên Windows:
  - .NET 10 SDK (`dotnet --version`)
  - Node.js LTS & npm (`node -v`, `npm -v`)
  - Docker & Docker Compose (`docker --version`)
  - Git version & IDE setup

### Task 2: Dựng PostgreSQL Local bằng Docker với Múi giờ UTC+7 (09:00 – 12:00)
- Cập nhật file `docker-compose.yml` bổ sung biến môi trường múi giờ: `TZ: Asia/Ho_Chi_Minh` (đáp ứng tiêu chuẩn phi chức năng `NFR-13`).
- Đảm bảo cấu hình volume lưu dữ liệu bền vững `postgres_data`.
- Hướng dẫn và kiểm tra trạng thái khởi động container PostgreSQL qua `docker compose up -d` và kết nối database `mbhms_db`.

### Task 3: Khởi tạo Khung Solution .NET 10 & Ứng dụng Next.js (13:30 – 16:30)
- Trong thư mục `backend/`: Khởi tạo solution .NET 10 trống:
  `dotnet new sln -n MBHMS`
- Trong thư mục `frontend/`: Khởi tạo ứng dụng Next.js TypeScript (App Router, Tailwind CSS, ESLint):
  `npx create-next-app@latest . --typescript --tailwind --eslint --app --src-dir --import-alias "@/*" --use-npm --yes`
- Kiểm tra biên dịch và package manager:
  - `dotnet build`
  - `npm run build` trong `frontend/`
- Gợi ý danh sách extension tối ưu cho VS Code / Visual Studio (C# Dev Kit, Tailwind CSS IntelliSense, Mermaid Preview, GitLens).

### Task 4: Tổng kết ngày (DoD) & Commit Hạ tầng lên Git (16:30 – 17:30)
- Tinh chỉnh `scripts/verify-scope.ps1` để hỗ trợ tiền tố thư mục.
- Kiểm toán scope qua `scripts/verify-scope.ps1`.
- Cập nhật nhật ký phát triển `docs/development/DEVELOPMENT_LOG.md`.
- Thực hiện commit chuẩn lên nhánh `develop`:
  `chore(infra): add docker-compose for local PostgreSQL with UTC+7 timezone`
